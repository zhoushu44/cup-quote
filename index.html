成本

材质吨价（每种材质一个价，改这里全材质生效） 纸钱 = 吨价 × 开料尺寸 × 克重
开料尺寸（只管长宽，决定一张纸能拼几片）
工艺参数 损耗 = 排版与加工的损耗比例

材质吨价：同一种材质不管多少克重，都是这一个吨价。
开料尺寸：整张纸的长×宽，决定能排多少扇片。克重不在这里，在「纸杯」页每个杯型的每一层上选，决定杯重和单张纸重量。
单只纸成本 = 整张纸钱（吨价 × 长 × 宽 × 克重）÷ (拼版数 × (1 − 损耗%))。
杯底：卷筒纸切圆片，不参与排版，按净面积 × 克重 × 吨价 ÷ (1 − 损耗%) 计（切圆片的损耗）。

纸杯（填上口 / 下口 / 杯高，选纸 → 拼版数、单杯重量、纸价自动算）
所有杯型可删除、可上下移动

结构：单层 / 双层 / 瓦楞 / 外贴。双层会展开成两行：内杯 + 外杯，各用各的材质、克重、开料、拼版与损耗。
材质 · 克重 · 开料：材质决定吨价（去「纸」页改），克重决定单张重量，开料尺寸决定拼版。三个随便组合，没有现成的纸会自动生成一张。
拼版数：一张纸能排多少片扇片。留空 = 按该纸长宽自动算（相邻两片正倒相扣；内层每行 = 斜高 + 14mm 卷边余量，外层 = 斜高），填了就用你的实际排版（错缝/蜂窝后请填实测值）。
损耗%：默认 8%，有效拼版 = 拼版 × (1 − 损耗%)。
单杯重量：扇片净重 × 层数 + 杯底圆片净重，自动算出来，可去「重量·箱规」填实测值覆盖。

重量 · 箱规
自动克重按「纸杯」表算 · 箱规需手填

自动克重：按成本页「纸杯」表的纸与拼版实时联动算出（净重，不含损耗），改纸杯表这里立刻变。实测克重可手填覆盖（有实测就填实测，总重和运费按实测算）。

茶叶杯 重量 · 箱规 单杯克重需手动填写

单杯克重：手动填（含杯身+茶叶，实测称重）。
箱规：每箱只数 + 长×宽×高(cm)，按所选包装方式分别填。

茶叶杯的价格是整单总价（不是单价）。改这里的数字，报价页会立即跟着变。

尺寸加价按单杯算。以欧8为基础，每升一档 +0.05。

包装加价按单杯算，乘上数量后计入总价。

发货天数 = 基准 + 杯型分组 + 结构 + 各工艺（累加）+ 克重（取最重一层）。例如：9盎司双层杯 + 烫金 + 压纹，268g → 7 + 0 + 2 + 2 + 1 + 0 = 12 天。

发货天数 = 基准 + 尺寸加天数 + 数量档加天数。例如：16盎司 + 1,000 杯 → 7 + 1 + 3 = 11 天。

单价 = 成本 ÷ (1 − 毛利率) × (1 + 税点)。税点由「开票类型」决定，也可单独调整。

纸杯知识

做报价先弄清四件事：多大容量、什么结构、多少克纸、什么工艺。这四项决定 90% 的成本。

01 规格与容量

行业用「盎司」称呼规格，但它是习惯叫法，不等于精确容量。同是 9oz，不同厂模具的上口、下口、高度不同，实际容量能差 10–20ml。报价和下单必须以上口×下口×高三项为准。

02 结构：单层 / 双层 / 中空 / 瓦楞 / 外贴

单层：一层纸 + 内壁淋膜，最轻最省，占定制杯绝大多数。装 90℃ 以上会烫手，一般配杯套。只需配 1 组纸。

双层：杯身外再复合一层纸（常见 250–300g），手感厚实、隔热更好，印刷面在外层。需配 2 组纸：内层杯身 + 外层外套。

中空：外层纸只在口底与内杯粘合，中间形成空气层，隔热最好，杯身明显变粗。行业常写「内 300g + 外 300g」。同样两层纸，但工艺更复杂、次品率高。

瓦楞：外层用瓦楞纸（280–340g），凹凸形成空气隔热层，隔热最强、手感最硬，但印刷精细度差，多用于热饮外卖。

外贴：成品杯身外套一层印刷纸或金属箔纸，做「换装」效果，起订量可以很低。

03 纸张与克重

纸杯原纸多用食品级白卡或杯纸，常见 198 / 210 / 230 / 248 / 268 / 280 / 300 / 320 / 350g。克重越高挺度越好、成本越高，但同克重不同浆料手感差别很大。

  • 198–230g：3–7oz 小杯、试饮杯
  • 248–268g：9 / 9.5oz 广告杯主力
  • 300g：12–22oz 奶茶杯标配
  • 320–350g：大容量、高端定制

克重直接决定纸钱：每只纸钱 = 面积 × 克重 × 纸价。268g 提到 300g，纸钱约多 12%。

04 淋膜与食品安全

主流是 PE 淋膜：单淋膜只在内壁，常规冷热饮够用；双淋膜内外两面，防潮更好，适合冰饮和外壁结露；PLA 淋膜可降解，耐温约 90℃，成本高 30–100%；水性涂层无塑化剂、可回收，成本最高。

合规底线：食品接触执行 GB 4806.8-2022，产品标准 GB/T 27590-2022。客户要质检报告时这两份是必备项。

版费是一次性费用，跟数量无关；返单版还在通常可免或减半。单列还是摊入单价，客户感受完全不同。

06 成本与报价构成

  • 原纸：面积 × 克重 × 纸价，占 35–50%
  • 淋膜：买的是淋膜纸，PE 涂膜含在纸价里，不再单独计
  • 印刷：油墨 + 版费 + 开机损耗
  • 成型：杯身、杯底、卷口，含电费人工
  • 后道：烫金、压纹、UV、覆膜、贴标
  • 包装物流：内袋 + 纸箱 + 运费
  • 损耗：常规 1–3%，小批量更高
  • 管理 + 利润 + 税：管理 3–6%，毛利 8–30%，增值税 13%

毛利率 ≠ 加价率。毛利率按售价算：单价 = 成本 ÷ (1 − 毛利率)。成本 0.06 想赚 15% 毛利，售价是 0.0706，不是 0.069。

07 箱规与物流

纸杯是泡货，体积重常大于实重，运费按立方算更准。3–7oz 约 2千–1万只/箱；9–9.5oz 约 1千–5千只/箱；12–22oz 约 1千–2.5千只/箱。中空和瓦楞杯杯身更粗，同数量箱规明显更大，运费务必按实际箱规算。

报价单写清「含运费 / 不含运费 / 偏远另议」，能省掉后期大半扯皮。

08 常见坑位

  • 只报盎司不报尺寸 —— 同 oz 不同模具会溢杯或显空
  • 把中空当双层报价 —— 成本差一大截
  • 漏算版费 —— 小批量版费可能比货值高
  • 没算损耗 —— 小单按 3–5% 更稳
  • 杯盖吸管漏报 —— 盖子和杯子分开计价
  • 含税不含税没说清 —— 13% 足以吃掉全部利润
  • 毛利率算成加价率 —— 报低了还以为赚了
  • 交期承诺太满 —— 常规 7–10 天，加急加价

09 标准与合规

  • GB/T 27590-2022《纸杯》：产品标准，2023-02-01 实施
  • GB 4806.8-2022：食品接触用纸和纸板材料及制品，2023-06-30 实施
  • GB 4806.1-2016：食品接触材料通用安全要求
  • 感官：无异味异物，油墨不得直接接触食品面
  • 出口另需 FDA（美）/ LFGB（德）等文件
